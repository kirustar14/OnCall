Listens to the room, keeps the record nobody has time to write, and speaks up only when the room contradicts itself.

The problem

Everything is said. Nothing is written.

Both facts were in the room. Twelve seconds apart. Neither was anywhere a person could check, and the patient is confused and cannot give a history. The failure is not skill. Spoken information has no memory.

What it does

One stream in. Three things out.

Voice in, voice out. Nobody stops to type, and there is no screen anyone has to look at.

The line it does not cross

It states. It never prescribes.

Software that recommends a therapy is a different regulatory and liability object than software that surfaces information a clinician can independently review. Every assertion carries a Provenance, and tests/test_ledger.py asserts the boundary so it cannot quietly drift back.

The flow — click any node

One loop, room to room.

Why it is allowed to interrupt

The word “penicillin” never appears.

Tier 1 cannot invent a conflict, because it is not the thing deciding one exists. Tier 2 is an open-ended agent for what no rule could enumerate: read-only, never writes to the ledger, and can never promote itself to critical.

Grounded in Medplum

One sentence becomes four resources.

Task is not a stretch here, it is what the resource is for — which means “show me everything nobody has taken” is a native FHIR query rather than a flag we invented and would have to maintain.

The stack, as one closed loop

Each one does something the loop could not close without.

The demo — fill the ledger, disturb it, drain it

Fifty-seven seconds in a trauma bay.
